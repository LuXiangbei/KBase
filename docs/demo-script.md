# 三分钟演示脚本

> 目标：让面试官在 3 分钟内看到「检索 → 引用 → 拒答 → 办事」四件事，并且每件事都有数字或断言支撑。

## 0. 准备（演示前 1 分钟）

```powershell
cd D:\DSH\KBase
.\.venv\Scripts\python.exe scripts\seed_demo.py --reset
.\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8010
```

浏览器打开 <http://127.0.0.1:8010>，确认右上角是「就绪」。

## 1. 开场（15 秒）

> 这是一个企业制度知识库助手。它不只回答，还要求每句话都有出处；找不到依据会拒答；实在解决不了，能直接开单转人工。今天演示四个动作：查条款、看引用、拒答、建单。

## 2. 查条款 + 引用（60 秒）

输入：**「年假天数按工龄怎么算？」**

- 回答会给出 5 / 10 / 15 天，句末带 `[1]`。
- 点 `[1]`，右侧展开原文片段与条款路径「休假与请假管理办法 / 第1条 年假 / 第 1 页」。
- 补一句：**「引用不是装饰，服务端会校验编号真实存在，没被正文引用的条款不会出现在最终引用里。」**

再输入：**「一线城市出差住宿标准是多少？」**

- 答 800 元/晚，引用《差旅报销标准》。
- 补一句：**「这条命中的是 BM25 路：条款编号和金额是向量的弱项，所以我做了双路召回 + RRF。」**

## 3. 拒答（40 秒）

输入：**「公司股票代码是多少？」**

- 回答明确说没有依据，不展示引用。
- 补一句：**「拒答靠两个信号：重排分和词面覆盖率。覆盖率阈值 0.16 是拿 84 条黄金集扫出来的，不是拍的。」**

对照组（可选）：把上面的问题换成「帮我查一下同事张三的工资明细」——普通员工检索不到 HR 专属文档，**候选集层面**就为空，不是生成后过滤。

## 4. 办事（50 秒）

输入：**「帮我建个工单，报销发票丢了，很急」**

- 若缺类别，会先追问一次（只问一个槽位）。
- 补齐后返回工单号与类别、紧急度。
- **再发一次完全相同的话** → 返回同一个工单号，标 `deduped`。
- 补一句：**「幂等键是 (user_id, request_id) 唯一索引；工具只有四个，白名单之外调不动。」**

## 5. 收尾（15 秒）

打开终端：

```powershell
.\.venv\Scripts\python.exe scripts\run_eval.py
```

> 84 条黄金集，Recall@5 1.00、拒答准确率 1.00、误拒率 0；75 条自动化测试全绿；360/768/1280 三个宽度实测无横向滚动。

补一句（诚实边界）：

> 默认用的是离线确定性嵌入，语义泛化有限，同义改写靠词表补；接真实模型只需改配置并重建索引，评测口径不变。

## 6. 常见追问与一句话回答

| 追问 | 回答 |
|---|---|
| 为什么不用 LangChain？ | 链路只有四段，自己写 300 行更好控；而且我要能改切分、融合和阈值。 |
| 数据量大了怎么办？ | 换 pgvector/Qdrant 分片，FTS 换 OpenSearch；接口层已经隔离。 |
| 怎么防注入？ | 检索内容当不可信数据、指令类文本在抽取时过滤、套取提示词在入口拦截。 |
| 怎么证明有效？ | 84 条黄金集 + 阈值门禁 + 三组对照；数字是本机跑的，口径写在报告里。 |
| 你最大的坑？ | 流式生成复用请求连接导致 SQLite 写锁，改成用户消息立即提交、生成结束用新连接。 |
